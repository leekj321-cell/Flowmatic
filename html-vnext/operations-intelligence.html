Operations Intelligence

현장 신호와 요청을 Event로 바꾸고, 담당·조치·완료까지 연결합니다.

설비 상태·현장 요청·자원 사용량을 같은 운영 문맥으로 기록하고 우선순위와 다음 행동을 연결합니다. 조달 요청 구조화와 비용·소비 이상 탐지는 현재 구현 범위에서 확인할 수 있습니다.

Operational event loop

읽고, 기록하고, 조치하고, 확인합니다.

현장 신호와 요청을 Event로 만들고, 담당·다음 행동·완료 조건을 같은 이력에 연결합니다.

  1. 01

    현장 읽기

    카메라·NC·검사·작업자·설비·현장 요청에서 필요한 신호를 수집합니다.

    • Camera
    • NC Code
    • Inspection
    • Operator
    • Machine
    • Request
  2. 02

    Event 기록

    품목·수량·시간·비용·상태·출처를 보존하고, 불확실한 값은 후보 상태로 남깁니다.

    • Request Event
    • Machine State Event
    • Resource Event
    • Anomaly Candidate
  3. 03

    다음 행동 연결

    Event의 우선순위와 책임 범위에 따라 검토·안내·알림·호출을 담당자에게 연결합니다.

    • Review
    • Guide
    • Alert
    • Call
    • Allocate
  4. 04

    응답 확인

    사람 또는 설비의 응답, 조치 결과, 완료 시점을 기록하고 Event를 종결합니다.

    • Acknowledged
    • Assigned
    • Resolved
    • Closed

Current scope

요청 구조화, 자원 정규화, 이상 후보 탐지를 기능 단위로 확인합니다.

Functional MVP

Procurement Intelligence

메일·채팅에서 품명·규격·수량·UOM·사용 문맥을 추출하고 confidence·reason과 함께 후보를 제시합니다. 담당자가 확인한 항목만 기존 요청양식으로 출력합니다.

  • 수량이 없을 때 1EA로 자동 확정하지 않음
  • 규격이 충돌할 때 자동 확정하지 않음
  • 알 수 없는 포장 단위를 임의 환산하지 않음
  • 수량과 사용 위치를 분리해 확인
  • 확인된 항목만 양식으로 출력

Functional MVP

Resource Economics

Tool·Consumable·Labor Event를 Tracked Operational Cost로 묶고 생산량과 가동시간으로 정규화합니다.

  • Cost / Production EA
  • Cost / Good EA
  • Man-hour / 1,000 EA
  • Consumption / 1,000 EA
  • Consumption / running hour

MVP candidate detection

Cost / Consumption Anomaly

Rolling Median + MAD와 EWMA로 생산량·가동시간 기준의 이상 후보를 식별하고 담당자 검토로 보냅니다.

  • Rolling Median + MAD
  • EWMA
  • Production-normalized candidates
  • Human review required

Prototype

Operations Composition Surface

Factory·Group·Period 공통 기준에서 필요한 운영 Module을 실행하고, Control Tower가 선택된 Module의 결과를 집계합니다.

  • Factory · Group · Period filter
  • Selected Module execution
  • Status · loss · owner · completion aggregation

Applied boundary

현재 연결된 비용과 데이터 범위를 구분합니다.

Tracked Operational Cost는 현재 연동된 공구·소모품·공수 비용을 포함합니다. Material·Energy·Maintenance·Outsource를 포괄하는 제조원가·회계원가와는 구분합니다.

실시간 ERP/MES Adapter, 재고·예산·공급사·수요예측, Maintenance 상관분석, 전체 Quality Adapter는 외부 데이터 연결 후 검증합니다.

Pilot

한 요청 흐름 또는 한 자원 지표부터 전후를 측정합니다.

  • 확정이 필요한 품목·규격·수량 규칙
  • 생산량·가동시간·사용량 기준선
  • 담당자 확인과 완료 조건

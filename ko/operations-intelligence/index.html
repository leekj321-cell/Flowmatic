Operations Intelligence 작동 방식

읽고, 기록하고,조치하고, 확인합니다.

카메라·NC·검사·작업자 입력을 Event로 기록하고, 담당·조치·완료까지 하나의 이력으로 닫습니다.

  1. 관찰카메라·NC 코드·작업자 입력에서 현장 신호를 수집합니다.
  2. 이벤트화원시 신호를 지연·위험·수요 Event로 변환합니다.
  3. 행동 연결Event별 알림·검토·안내·호출을 지정합니다.
  4. 확인사람 또는 설비의 응답을 기록하고 Event를 종결합니다.

Functional MVP

Procurement Intelligence

메일·채팅에서 품명·규격·수량·UOM·문맥을 추출하고 confidence·reason과 함께 후보를 제시합니다. 담당자 확인 항목만 기존 요청양식으로 출력합니다.

  • No silent 1EA default for missing quantity
  • No auto-confirm on conflicting specifications
  • No arbitrary conversion of unknown pack units
  • Quantity / use-location split
  • Confirmed-only template export

Functional MVP

Resource Economics

Tool·Consumable·Labor event를 Tracked Operational Cost로 묶고 생산량과 가동시간으로 정규화합니다.

  • Cost / Production EA
  • Cost / Good EA
  • Man-hour / 1,000 EA
  • Consumption / 1,000 EA
  • Consumption / running hour

MVP candidate detection

Cost / Consumption Anomaly

Rolling Median + MAD와 EWMA로 이상 후보를 식별합니다. 예측정비 원인분석은 범위에 포함되지 않습니다.

  • Rolling Median + MAD
  • EWMA
  • Production-normalized candidates
  • Human review remains required

Prototype

Operations Composition Surface

Factory·Group·Period 공통 기준에서 필요한 운영 Module을 실행하고, Control Tower가 선택된 Module의 결과를 집계합니다.

  • Real-time ERP/MES adapters pending
  • Live inventory / budget / supplier / forecasting pending
  • Maintenance correlation and full Quality adapter pending

적용 범위

Tracked Operational Cost는 현재 연동된 공구·소모품·공수 비용만 포함합니다. Material·Energy·Maintenance·Outsource를 포괄하는 제조원가·회계원가는 아닙니다.

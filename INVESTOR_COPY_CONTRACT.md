# Flowmatic Investor Copy Contract

**Public homepage release:** `2026.09.19-r6-investor`

This contract keeps Flowmatic's public website readable to investors and manufacturing customers without weakening the product architecture.

## Narrative order

1. Hero: customer, problem, result, current product
2. CURRENT product proof
3. Drawing-to-production manufacturing journey
4. Traditional full-stack vs Flowmatic L1–L6 comparison
5. Progressive automation
6. Production-ready outputs
7. Design → Build → Run → Improve loop
8. 4–8 week PILOT, KPI, ROI
9. Expansion: workflow → line → factory
10. Final pilot CTA

## Claim boundaries

- **CURRENT:** features that can be demonstrated now.
- **PILOT:** value or integration that must be validated in a customer environment.
- **TARGET:** long-range Factory OS scope.

Do not present PILOT or TARGET capability as completed CURRENT functionality.

## Required business language

The public homepage must make these visible:

- Primary users: manufacturing/process engineering, quality, line operations.
- Budget owners: plant/manufacturing leadership, operations executive, CEO.
- One product or one line as the initial scope.
- 4–8 week pilot.
- Baseline → Flowmatic → KPI comparison → ROI decision → expansion.
- No unsupported performance percentages.

## Public forbidden terms

Do not expose these terms in normal public copy:

- STC-lite
- Blueprint R2
- L3–L6 CORE
- CORE / OPTIONAL
- INFERRED
- manifest
- hash
- Safety Contract

Technical implementation terms belong in explicitly separated technical-detail content only.

## Typography and hierarchy

- Hero H1 should remain dominant but must not crowd out the product proof.
- Product proof is the second section and receives stronger visual emphasis than architecture.
- Section headings should read as customer outcomes, not module names.
- Long paragraphs are avoided; supporting text is generally one short paragraph.
- Desktop pilot cards use a 3×2 rhythm; mobile collapses to one column.
- CURRENT / PILOT / TARGET badges are visually distinct but subordinate to the main headline.

## Multilingual rule

Korean approved copy is the source of truth. English and Arabic must preserve the same CURRENT / PILOT / TARGET boundaries, pilot model, and business meaning without adding performance claims.

Functional MVP

Procurement Intelligence

Extract item, specification, quantity, UOM, and context from free-text mail or chat; present candidates with confidence and reason; export confirmed items only to the existing request template.

  • No silent 1EA default for missing quantity
  • No auto-confirm on conflicting specifications
  • No arbitrary conversion of unknown pack units
  • Quantity / use-location split
  • Confirmed-only template export

Functional MVP

Resource Economics

Combine Tool, Consumable, and Labor events as Tracked Operational Cost and normalize them by production and running time.

  • Cost / Production EA
  • Cost / Good EA
  • Man-hour / 1,000 EA
  • Consumption / 1,000 EA
  • Consumption / running hour
